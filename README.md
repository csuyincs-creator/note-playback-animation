# 谱面 · 音符动画工作台

可复用的本地网页：将 MusicXML/MXL 与 MIDI 映射到真实曲谱符头，生成双声部 3D 动画。可调镜头、光色、行进方向和播放速度，保存项目 JSON，并将整首实时录制为视频。

## 启动

需要 Node.js 20.19+。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。`npm run build` 可生成静态网页到 `dist/`，`npm test -- --run` 运行映射与录制格式测试。

## 使用

1. 上传对应的 `.mxl`、`.musicxml` 或 `.xml` 曲谱及 `.mid`、`.midi` 文件。
2. 点击「生成曲谱动画」，检查映射百分比，再播放或拖动时间轴。
3. 可选上传与 MIDI 同步的 WAV/MP3/OGG 音频用于试听和录制。
4. 调整方向、镜头距离、跟随强度、柔光和两声部色彩；点击「放大」查看画面。
5. 点击「录制整首」会从 00:00 以 1× 播放到结束，实时采集 3D 画布和音频，结束时下载视频。MP4 编码可用时优先 MP4，否则尝试 WebM。录制期间可以取消。
6. 保存项目 JSON，可在下次打开网页时重新导入。参数也会自动保存在当前浏览器。

## 示例项目

「久石让《Summer》合奏版」仅在开发模式提供本地预览。动画只显示钢琴左右手对应的谱面和双球；完整 27 轨 MIDI 通过本地 GeneralUser GS 音源合成播放，不是久石让的原版录音。谱面与 MIDI 来自 [ScoreBase 曲目页](https://scorebase.org/scores/213453)，页面标注 PDMX，但该曲的版权许可尚未独立核验。它们和音源文件只保存在本地 `examples/summer-local/`，此目录由 `.gitignore` 排除，且只经 Vite 开发中间件读取，不会进入生产构建。GeneralUser GS 的许可证见同目录 `GENERALUSER-LICENSE.txt`。

另有一对供解析器测试的 MXL/MIDI 文件，以及一键载入的舒伯特《降A大调即兴曲 D.899 No.4》30 秒钢琴片段；片段包含 MusicXML、MIDI 和采样钢琴 MP3，来源 PDF 与说明在 `public/examples/real-project/`。

## 范围与限制

曲谱解析和匹配都在浏览器执行。钢琴声部按音高与拍位匹配；反复段落、移调、装饰音或不同版本可能需要人工核对。整曲视频采用实时录制，约 4 分钟的曲目需要相近的录制时间；输出格式和画质取决于浏览器编码器与设备性能。上传音频的同步需由用户自行核验。
